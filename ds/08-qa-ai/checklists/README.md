# QA checklists

Each outcome's checklist is the "Checklist before delivery" at the end of its skill, served with the format profile as `format_profile.skill`:

| Outcome | Checklist in |
|---|---|
| Decks | `07-skills/decks/SKILL.md` |
| A4 documents | `07-skills/a4-documents/SKILL.md` |
| Newsletters | `07-skills/newsletters/SKILL.md` |
| Architectures | `07-skills/architectures/SKILL.md` |
| Social media | `07-skills/social-media/SKILL.md` |

Images, unique A4 and case studies have no skill yet, so no checklist.

## For every outcome

- [ ] The user's content is unchanged; nothing copied from a template.
- [ ] `check_design` verdict is pass.
- [ ] The format's checklist is done.
- [ ] Assets are real files from the asset library, on their allowed backgrounds.
- [ ] Nothing overflows; no text below the format minimum.
- [ ] One HTML file, named `<topic>_<outcometype>_faclon_<YYYY-MM-DD>.html`.
- [ ] Delivered in the chat with a note of anything flagged.
