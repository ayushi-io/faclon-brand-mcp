# Assets: product screenshots

There is no product screenshot library, and none is planned soon (decision `product-screens-and-photos`, 2026-10-30). A product screen comes from the user; without one, place the `DASHBOARD_MOCKUP_<NAME>` placeholder (container/secondary, 1px dashed border/strong, radius/3xl, the label centred in text/secondary) and list it in the delivery note. Never draw a fake product UI.
