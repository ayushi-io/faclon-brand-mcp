# File naming

Every finished file is named:

`<topic>_<outcometype>_faclon_<date>.html`

- **topic:** what the piece is about, from the user's title or subject: 1 to 5 words, lowercase, words joined by hyphens, no special characters. For example `pellet-vision-roi`.
- **outcometype:** the format id of the outcome: `deck`, `document`, `newsletter`, `architecture` or `social`.
- **faclon:** always the word `faclon`.
- **date:** the day the file is made, as `YYYY-MM-DD`.
- Parts are joined by underscores; the extension is `.html`.

Examples:

- `pellet-vision-roi_deck_faclon_2026-10-27.html`
- `cement-plant-case-study_social_faclon_2026-10-27.html`
- `steam-trap-monitoring_architecture_faclon_2026-10-27.html`

If the topic is unclear, use the deliverable's title; never invent a topic the user did not give.
