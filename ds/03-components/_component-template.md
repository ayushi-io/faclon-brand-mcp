# Component spec template

Every component is specified with these parts. For the built components, `components.json` carries them as fields (shown in brackets); a component still to design is written with this template before it is built in Figma.

## Purpose

What the component is for and when to use it (`use`).

## Anatomy

Its parts in order, each with the component, text role or tokens it uses (`parts`, `contains`), and the surface: fill, border, border width, radius (`surface`), padding and gap (`layout`).

## Variants

Each variant property and its options, and what changes between them (`props`, `variants`).

## Do / don't

When to choose it over a similar component, and what never to change (tokens are never restyled).
