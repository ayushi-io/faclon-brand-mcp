# Templates: architectures

6 architecture templates: machine monitoring, heat exchanger process diagram, repeated steam traps, substation cloud architecture and the camera-based vision system (JSPL particle size analysis), plus the Icon + content reference showing the four device styles (boxed tag, tag, label, caption). Each entry in `templates.json` has its section and purpose, theme, layout notes, Figma node and a thumbnail in `thumbnails/`. Served by `get_brand_guidelines(section: "templates", format_profile: "architecture")`, thumbnails at `/templates/architectures/thumbnails/<file>`.

Templates show layout, composition, hierarchy and rhythm only. Never copy their text, numbers, claims, client names or logos, and build every value from the design system.
