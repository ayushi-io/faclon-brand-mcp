# Templates: architectures

5 architecture templates: machine monitoring, heat exchanger process diagram, repeated steam traps, substation cloud architecture and the camera-based vision system (JSPL particle size analysis). Each entry in `templates.json` has its section and purpose, theme, layout notes, Figma node and a thumbnail in `thumbnails/`. Served by `get_brand_guidelines(section: "templates", format_profile: "architecture")`, thumbnails at `/templates/architectures/thumbnails/<file>`.

Templates show layout, composition, hierarchy and rhythm only. Never copy their text, numbers, claims, client names or logos, and build every value from the design system.
